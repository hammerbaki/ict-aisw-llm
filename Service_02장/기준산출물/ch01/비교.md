# 비교 기록 (2장 기준 산출물)

`가_한줄/`, `나_요구목록/`, `다_보강/`의 프로그램을 점검표대로 직접 실행해 채운 예시이다. (가)의 `job_deadline.py`는 한 줄 요청을 받은 코딩 도구가 흔히 내놓는 형태를 집필자가 재현한 것이고, 실제 모델의 출력이 아니다. 학생의 (가) 결과는 이것과 다르며, 대화형(`input()`) 프로그램, 웹 페이지, CSV를 읽는 프로그램이 나올 수도 있다. 판정의 형식과 근거를 쓰는 수준을 보이는 데 쓴다.

- 실행: 2026-11-14(1~4부), 2026-11-17(5부), Windows 11의 Git Bash, Python 3.13.7. macOS에서의 실행은 수업 전 리허설에서 확인한다.
- (가)는 CSV를 읽지 못하므로 네 건(가람소프트, 바른클라우드, 누리데이터, 새봄헬스케어)을 `add` 명령으로 넣고 4~7번을 판정하였다. 기준일을 줄 수 없어 실행한 날(2026-11-14) 기준의 D 값이다.

## 3부. AI가 스스로 정한 것

| (가)에서 AI가 정한 것 | (나)에서 AI가 정한 것 |
|---|---|
| 1. 공고를 `jobs.json`에 저장하고 `add`·`list`·`remove` 세 명령으로 관리한다 | 1. 같은 날 마감인 공고(누리, 이음)는 파일 순서대로 둔다 |
| 2. 3일 이내를 「임박」으로 보고 이모지로 표시한다 | 2. 칸 사이를 공백 두 칸으로 띄우고 `[임박]`이 없는 줄은 공백 여섯 칸으로 맞춘다 |
| 3. 공고마다 번호(ID)를 붙인다 | 3. `--today`에 잘못된 날짜를 주면 오류 문장을 내고 종료 코드 2로 끝낸다 |

## 4부. 요구 목록이 정하지 않은 것

1. 모든 공고가 지난 공고일 때 `표시할 공고가 없습니다.`와 `지난 공고 N건`을 둘 다 출력하는가, 하나만 출력하는가.
2. 같은 날 마감인 공고의 순서(회사 이름순인가, 파일 순서인가).
3. 머리글이 `회사,공고명,마감일`이 아닌 파일(열 순서가 다르거나 열이 빠진 파일)을 어떻게 다루는가.
4. `--today`의 형식이 틀렸을 때의 문구와 종료 코드.

## 5부. 빠진 요구의 보강: 13번과 (다)의 판정

**문제의 재현.** (나) 예시로 13번 명령을 실행한 결과이다.

- (나)의 13번 출력: `표시할 공고가 없습니다.` 다음 줄에 `지난 공고 3건` (두 줄, 종료 코드 0)
- (나)의 13번 판정: X. 10번과 7번을 따로 지켜 두 줄을 낸다. 요구 목록이 둘이 겹치는 경우를 정하지 않았으므로 프로그램의 잘못이라기보다 요구 목록의 빈틈이다(4부 1번).

**(다)의 판정.** `교수/예시결과/다_보강/dday.py`로 `bash 점검_모아보기.sh 다_보강/dday.py`를 실행해 1~13번을 판정하였다.

| 번호 | (다) 판정 | (다) 근거 |
|---|---|---|
| 1~12 | 12/12 | 1~12번 출력이 (나)와 한 글자도 다르지 않다. 10번(빈 목록)은 여전히 `표시할 공고가 없습니다.` 한 줄 |
| 13 | O | `표시할 공고가 없습니다. (지난 공고 3건)` 한 줄, 종료 코드 0 |

- 회귀: 없음. 학생 결과에서는 10번(빈 목록에도 `(지난 공고 0건)`을 붙임)과, 새로 만든 판이 1~12번의 문구나 칸 간격을 (나)와 다르게 정해 5번이 △가 되는 경우가 나올 수 있다.
- (다)에서 AI가 새로 정한 것 하나: 이 예시는 13번의 한 줄을 낸 뒤 바로 끝낸다. 지난 공고 건수를 괄호 안에 넣는 형식은 요구가 정했으나, 이 줄을 표준 출력으로 낸다는 것도 13번이 정하였다. 요구가 정하지 않은 것은 종료 코드(이 예시는 0)이다.

## 6부. 정리

1. 두 결과의 가장 큰 차이: (가)는 공고를 직접 입력해 저장하는 관리 도구가 되었고, (나)는 파일을 읽어 알림 목록을 내는 도구가 되었다. 같은 「마감일 알림」이라는 말에서 프로그램의 모양 자체가 달라졌다.
2. (나)에서 X나 △가 나온 항목: 이 예시에는 없다. 학생 결과에서는 5번(칸 순서), 8번(줄 번호를 머리글부터 세는지), 12번(stderr)이 자주 어긋날 것으로 예상한다.
3. (다)가 보여 준 것: 13번을 요구 목록에 더해 다시 만들자 13번이 `O`가 되었고 1~12번에 회귀가 없었다. 다음에 더할 요구: 같은 날 마감인 공고의 순서.
