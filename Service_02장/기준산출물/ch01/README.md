# 1장 기준 산출물

1장의 결과(`~/llm-service-lab/ch01/`)가 없는 학습자가 2장을 시작할 수 있도록 둔 대체 산출물이다. 1장에서 각자 만든 것이 있으면 그것을 쓰고, 이 폴더는 쓰지 않는다.

- 1장 키트의 재료(`연습/`, `점검자료/`와 그 안의 `.gitattributes`, `점검_모아보기.sh`, `요청문_양식.md`, `점검표_양식.md`)
- `가_한줄/job_deadline.py`: 한 줄 요청으로 만든 프로그램의 예(1장 키트의 교수용 예시 결과를 옮김. 실제 모델의 출력이 아니다)
- `나_요구목록/dday.py`: 요구 목록 요청으로 만든 프로그램의 예(같음)
- `다_보강/dday.py`: 요구 13번을 더한 요구 목록 요청으로 만든 프로그램의 예(같음)
- `비교.md`: 점검표에 따른 판정 기록 예(1~6부. 5부는 13번과 (다)의 판정)
- `요청문.md`: 요청문 양식(기록 없음)

1장의 `첫사용/days_left.py`(4절의 연습)는 들어 있지 않다.

2장 0-2에서 `cp -rn ~/kits/Service_02장/기준산출물/ch01 ~/llm-service-lab/`로 복사하고, 3-4의 첫 커밋에 넣는다.
