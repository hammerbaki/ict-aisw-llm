# 11장 기준산출물

1~7장을 마치지 못한 학습자를 위한 견본이다. 7장 키트의 `기준산출물/`(2~6장의 부품, 그 폴더의 README는 빼었다)에 7장 키트의 `조립/`(7장에서 고친 `.claude/settings.json`, `CLAUDE.md`, `.claude/agents/reviewer.md`)을 덮어 만들었다(정합 작업 2026-11-14, 결정 11 개편으로 2026-11-17 다시 만듦: 6장의 Windows 훅 수정, `.mcp.json`의 `python` 꼴, 가상 환경 규칙의 `CLAUDE.md`, 4장 개편본 플러그인). 이미 앞 장의 파일이 있는 학습자는 쓰지 않는다(`cp -rn`은 있는 파일을 덮어쓰지 않는다).

| 파일 | 장 | 11장에서 쓰는 곳 |
|---|---|---|
| `CLAUDE.md`, `.claude/rules/`, `docs/운영/저장소규약.md` | 3·7 | 비밀 정보 규칙(지시)의 출발점, 위협 모델이 가리키는 규약. `CLAUDE.md`는 7장 조립본이다 |
| `.claude/settings.json` | 3·6·7 | 거부 규칙과 훅을 더할 설정(거부 규칙 3개, 보호 파일 훅, 편집 뒤 테스트 훅, 7장의 Stop 훅). 명령 규칙은 가상 환경을 켠 `python …` 꼴이다 |
| `.claude/hooks/`(`protect.sh`, `protected.txt`, `run_tests.sh`, `stop_gate.sh`, `check_hooks.sh`, `samples/`) | 6 | 보호 파일 훅(6장 개편본: `to_slash`, 대소문자 무시, 파이썬은 `.venv/Scripts/python.exe` 먼저). 11장의 `block_secrets.py`와 `block_secrets.sh`가 옆에 더해진다. `run_tests.sh`는 동결 검사를 함께 돌리므로 11-3절에서 테스트를 더한 뒤 `freeze --update`가 필요하다 |
| `.claude/agents/reviewer.md` | 6·7 | 도구를 제한한 서브에이전트의 본보기(검토 규칙 RV1~RV8). 11-11절에서 위협 모델 검토에 쓴다 |
| `plugins/jobprep-ops/`, `.claude-plugin/marketplace.json` | 4 | 공급망 점검(9절, 11-10절)의 대상. 4장 키트의 `예비/`·`재료/`(개편본)와 같다 |
| `.mcp.json`, `mcp/ops_server.py`(서버 이름 `jobprep-ops`, 도구 `error_summary`, `status_counts`, `slow_requests`, `read_log`) | 5 | 간접 주입의 통로(운영 기록)와 공급망 점검의 대상. `.mcp.json`은 `"command": "python"` 꼴이다(5장에서 Windows의 `.venv/bin/python` 꼴이 연결에 실패함을 확인). 실행하려면 `mcp==2.3.0`이 필요하다(이 장에서는 실행하지 않는다) |
| `tests/.baseline.json`, `tools/test_guard.py` | 2 | 테스트 동결(새 형식, 파일 11개). 2장 정답 저장소의 기록이므로 2장을 하지 않은 저장소에서는 `TEST_CHANGED`(`수정: pytest.ini`, `삭제` 셋)가 난다(강의안 0-2절) |

10장의 역할 에이전트(`.claude/agents/`의 다른 파일)와 `ops/multi/`, 7장의 측정 도구(`ops/harness/`)와 하네스 플러그인(`plugins/jobprep-harness/`)은 넣지 않았다. 11장의 실습은 그것 없이 돈다. 10장을 마친 학습자는 위협 모델의 「진입점」과 「치명적 조합 점검」 표에 역할 에이전트를 더한다.
