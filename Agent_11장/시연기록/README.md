# 시연기록 (Agent_11장, 7-4절과 11절)

실제 모델에 주입 시나리오를 넣는 실행과, Windows에서 돌지 않는 샌드박스는 교수 시연이다. 실제 모델의 반응은 같은 입력에도 매번 다르고, 시나리오를 되풀이해 넣으면 계정의 사용량을 많이 쓰기 때문이다(편성표 결정 11의 실행 상한). 교수는 시연 세션의 대화를 `/export`로 저장해 가짜 키와 개인 경로가 없는지 확인한 뒤 이 폴더에 올린다.

| 올라오는 때 | 파일 | 내용 |
|---|---|---|
| 시연 A 뒤(11-2절 무렵) | `시연A_대책전.txt` | 대책을 넣기 전의 저장소에서 `issue_42.md`를 읽힌 대화 |
| 시연 A 뒤(11-7절 무렵) | `시연A_대책후.txt` | 대책을 넣은 저장소에서 같은 요청과 비밀 파일 읽기 요청을 보낸 대화 |
| 시연 E 뒤(선택) | `시연E_샌드박스.txt` | macOS 또는 WSL2에서 샌드박스를 켜고 파이썬 한 줄 우회를 시도한 대화 |

기록 파일의 머리에는 실행 날짜, Claude Code 판, 운영체제, 모델이 있다. 머리에 「견본」이라고 적힌 기록은 실제 모델의 출력이 아니라 집필자가 지어낸 예시이다(시연 기록을 만들지 못한 때에만 배포한다).

학습자는 이 폴더의 파일을 고치지 않는다. 강의안 7-4절의 안내대로 실제 모델이 보인 반응을 `security/결과기록.md`의 3절에 한 줄로 옮긴다.
