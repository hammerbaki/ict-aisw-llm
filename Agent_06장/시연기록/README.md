# 시연기록 (Agent_06장, 10절)

6장의 검토 전담 서브에이전트(`reviewer`)를 실제 모델로 여러 번 돌리는 실행은 교수 시연이다. 같은 정의를 같은 대상에 여러 번 돌려야 성능을 말할 수 있고, 그 반복은 계정의 사용량을 많이 쓰기 때문이다(편성표 결정 11의 실행 상한). 교수는 수업 전에 헤드리스 실행(`claude -p --agent reviewer`)으로 기록을 만들고, 수업 중에 두 번 나누어 이 폴더에 올린다.

| 올라오는 때 | 파일 | 내용 |
|---|---|---|
| 1차(10-5절 시연 뒤) | `정상변경_가.md` | 위반이 없는 변경(훅 커밋)에 1회차 정의를 투입한 기록 |
| 1차 | `1회차_가.md`, `1회차_나.md`, `1회차_다.md` | 같은 1회차 정의를 검토 연습 diff에 세 번 투입한 기록 |
| 1차 | `정의_1회차.md` | 1회차 기록에 쓴 정의 파일(양식을 최소로 채운 판) |
| 2차(10-6절 정답 공개 뒤) | `2회차_가.md` | 빈틈을 메운 정의로 같은 diff에 투입한 기록 |
| 2차 | `변형_가.md` | 규칙 밖의 위반(경로 우회) 한 줄을 더 심은 diff에 투입한 기록 |
| 2차 | `정의_2회차.md` | 2회차와 변형 기록에 쓴 정의 파일 |

기록 파일의 머리에는 실행 날짜, Claude Code 판, 모델, 정의 파일, 검토 대상의 크기가 있고, `---` 아래가 검토자의 보고 원문이다. 머리에 「견본」이라고 적힌 기록은 실제 모델의 출력이 아니라 집필자가 지어낸 예시이다(시연 기록을 만들지 못한 때에만 배포한다).

학습자는 이 폴더의 파일을 고치지 않는다. 강의안 10절의 안내대로 필요한 부분을 `docs/운영/검토자검증.md`에 옮긴다.
