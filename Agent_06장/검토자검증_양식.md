# 검토자 검증 기록

- 작성자: 「이름」
- 날짜: 「YYYY-MM-DD」
- Claude Code 버전: 「claude --version의 출력」
- 내 검토자 정의: `.claude/agents/reviewer.md` (커밋 「짧은 해시」)
- 검토 기록: 「교수 시연 기록 또는 견본 기록」, 기록의 Claude Code 판과 모델 「」
- 검토 대상: 브랜치 `review-drill`, `.review/target.diff` (바뀐 파일 「N」개)

## 1. 훅 점검 결과

`bash .claude/hooks/check_hooks.sh`의 마지막 줄을 그대로 옮긴다.

```text
「== 결과: 통과 N, 실패 M」
```

Claude Code 안에서 관찰한 훅의 동작을 한 줄씩 적는다.

| 시도 | 기대한 동작 | 관찰한 동작 |
|---|---|---|
| `.env`에 한 줄 더하기를 요청 | protect.sh가 막고 이유가 Claude에게 전달된다 | 「」 |
| `api/jobs.py`에 일부러 문법 오류를 넣게 요청 | run_tests.sh가 문법 오류를 알리고 Claude가 고친다 | 「」 |

## 2. 검토자의 보고 (1회차_가 기록)

교수가 배포한 `1회차_가.md`에서 「---」 아래의 보고(위반 표, 검토한 파일, 규칙 밖의 관찰, 확인하지 못한 것)를 그대로 옮긴다. 고치거나 줄이지 않는다.

「검토자의 보고를 붙여 넣는다」
