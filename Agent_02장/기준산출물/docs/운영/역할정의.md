# jobprep 운영 에이전트 시스템 역할 정의서 v0.1 (2장 기준산출물, 줄인 판)

> 1장을 마치지 못한 학습자를 위해 2장 키트가 넣는 견본이다. 1장의 형식을 따르되, 2장이 쓰는 두 역할(구현, 테스트)만 담았다. 1장의 최소 개수(역할 5개)에는 못 미친다. 1장을 마친 학습자는 자기 문서를 쓴다.

| 항목 | 내용 |
|---|---|
| 대상 | `jobprep`을 운영하는 에이전트들과 사람(운영 책임자) |
| 작성 | 2장 키트의 기준산출물, 2026-11-14 |
| 근거 | `docs/운영/운영요건.md`, 「AI에이전트 기획 및 개발」 1장 9절, 2장 |

## 1. 역할 요약 (2장 관련)

| ID | 역할 | 한 줄 설명 | 자율성 수준(1장 4절) | 구현하는 장 |
|---|---|---|---|---|
| R2 | 구현 | 동결한 테스트가 통과하도록 코드를 고친다 | 3 상담자 | 2, 7, 8 |
| R3 | 테스트 | 요구를 테스트로 바꾸고 실행해 판정한다 | 3 상담자 | 2, 6, 12 |
| 사람 | 운영 책임자 | 테스트의 동결, 커밋, 병합, 태그를 결정한다 | - | 전 장 |

## 2. 역할

### R2 구현

| 항목 | 내용 |
|---|---|
| 목적 | 동결한 테스트 하나(요구 하나)를 통과하도록 구현한다 |
| 권한 | 읽기: 저장소 전체(`.env` 제외). 쓰기: `api/`, `rag/`, `web/`. 실행: `pytest`, `python tools/test_guard.py check`. 금지: `tests/`, `pytest.ini`, `conftest.py`, `tools/test_guard.py`의 수정·삭제·생성, `test_guard.py freeze`, git 명령(2장에서는 커밋도 사람이 한다), `.env`·`data/` 수정 |
| 입력 | 동결한 테스트, 요구 문장, 지시문(2장 키트의 `지시문_양식.md`) |
| 출력 | 구현의 변경, 변경 요약, 실행한 명령과 결과 줄 |
| 완료 조건 | `pytest -q`에 실패가 없고 `test_guard.py check`가 `TEST_UNCHANGED`이며, 그 결과 줄이 보고에 있다 |
| 사람 승인 지점 | 지시한 범위 밖의 파일을 고쳐야 할 때, 테스트가 틀렸다고 판단할 때 |
| 관련 운영 요건 | OR-SEC-07, OR-REL-04, OR-REL-07 |

### R3 테스트

| 항목 | 내용 |
|---|---|
| 목적 | 인수 조건을 실패하는 테스트로 먼저 쓰고, 구현 뒤 다시 실행해 판정한다 |
| 권한 | 읽기: 저장소 전체(`.env` 제외). 쓰기: `tests/`의 새 테스트 파일. 실행: `pytest`. 금지: `api/`·`rag/`·`web/` 수정, 동결된 테스트의 수정·삭제 |
| 입력 | 요구사항명세서의 요구 문장과 인수 조건 |
| 출력 | 새 테스트(처음에는 실패), 동결 기록, 판정 기록(실패 → 통과, 통과 수) |
| 완료 조건 | 새 테스트가 구현 전에는 실패하고 구현 뒤에는 통과하며, 테스트 수가 줄지 않았다 |
| 사람 승인 지점 | 테스트를 동결할 때(동결 뒤에는 사람만 `freeze --update`로 기록을 바꾼다) |
| 관련 운영 요건 | OR-CON-06, OR-REP-01 |
