# jobprep 운영 요건 명세 v0.1 (2장 기준산출물, 줄인 판)

> 1장을 마치지 못한 학습자를 위해 2장 키트가 넣는 견본이다. 1장의 형식(`docs/운영/` 양식, `ops/check/check_ops.py reqs`)을 따르되, 2장(테스트 주도 개발)이 충족하는 요건만 담았다. 그래서 1장의 최소 개수(15개, 분류마다 3개)에는 못 미친다. 1장을 마친 학습자는 자기 문서를 쓰고, 아래 요건과 뜻이 같은 자기 요건의 ID로 읽는다.

| 항목 | 내용 |
|---|---|
| 대상 | 기준 저장소 `jobprep`과 이를 운영하는 「jobprep 운영 에이전트 시스템」 |
| 작성 | 2장 키트의 기준산출물, 2026-11-14 |
| 근거 | `docs/요구사항명세서.md` v1.1, 「AI에이전트 기획 및 개발」 1장, 2장 |
