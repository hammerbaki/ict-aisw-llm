# 5장 실습 키트: 사용자 조사와 페르소나 설계

「LLM 서비스 개발」 5장(학사 6주차)의 실습 재료이다. 강의안 `Service_05장_학생용.md`의 0절에서 키트 저장소(`~/kits-repo`, 부록 A-12)로부터 이 폴더를 `~/kits/Service_05장/`로 받고, 양식을 개인 실습 저장소의 `ch05/`로 복사해 쓴다. 키트 폴더 자체는 저장소에 넣지 않는다.

## 쓰는 순서

1. 0절: 키트를 받고, `ch04/`가 있는지 확인한다. 없으면 `기준산출물/ch04/`를 복사한다.
2. 따라 하기: 5-6에서 `number_lines.py`를, 10-3에서 `check_trace.py`와 대조표를 예시 기록과 연습 파일로 시험한다(연습 폴더 `~/ch05_연습`).
3. 핵심 실습: 인터뷰 가이드 → 인터뷰 1회차(번호, 비식별 검사, 참여자 확인) → 인터뷰 2회차 → 친화도(Claude Code 초안) → 페르소나 초안과 첫 검사 → 근거 없는 주장 찾아 고치기(대조표) → 문제 정의 → 커밋.

## 도구 실행 예

도구는 파이썬 표준 라이브러리만 쓴다. 따로 설치할 것이 없다. 가상 환경을 켠 터미널(부록 A-13)에서 저장소(`~/llm-service-lab`)로 이동해 실행한다. Windows의 Git Bash에는 `python3`이 없으므로 `python`으로 부른다.

```bash
python ~/kits/Service_05장/tools/number_lines.py ch05/기록/인터뷰_01.md
python ~/kits/Service_05장/tools/check_pii.py ch05/기록 --names ~/ch05_이름목록.txt
python ~/kits/Service_05장/tools/check_trace.py ch05/친화도.md ch05/페르소나.md ch05/문제정의.md --records ch05/기록 --report ch05/대조표.md
```

`check_trace.py`의 판정: 실패(없는 파일·줄, 틀린 형식)나 누락(근거 표기가 없는 주장 줄)이 있으면 종료 코드 1이다. 경고(진행자의 질문이나 메모를 인용, 6줄 이상의 범위)는 통과를 막지 않는다. 이 검사는 "인용한 줄이 있는가"만 본다. "그 줄이 주장을 뒷받침하는가"는 사람이 `--report`로 만든 대조표를 읽고 판정한다.

도구가 쓰는 파일(`number_lines.py`가 고친 기록, `check_trace.py --report`의 대조표)은 Windows에서도 줄 끝이 LF이다. 파이썬의 `write_text`는 Windows에서 줄 끝을 CRLF로 바꾸므로, 고치기 전에는 Windows에서 만든 기록과 대조표만 CRLF가 되어 저장소의 줄 끝이 운영체제마다 달랐다. 강의안은 판정 행을 셀 때 줄 끝에 `[[:space:]]*`를 둔 패턴을 쓴다. 줄 끝에 CR이 남은 파일에서도 세기 위해서이다(Git Bash의 grep 3.0은 CRLF 줄도 세었다. 다른 grep은 확인하지 못하였다).

## 테스트

가상 환경은 과목 전체에 하나인 `~/llm-service-lab/.venv`를 쓴다(부록 A-13). 켠 터미널에서 실행한다.

```bash
cd ~/kits/Service_05장
python -m pip install -r requirements.txt
python -m pytest -q -p no:cacheprovider
```

`-p no:cacheprovider`는 키트 폴더에 `.pytest_cache`를 남기지 않게 한다. 2026-11-17에 Windows 11의 Git Bash, Python 3.13.7, pytest 9.2.0에서 37개 테스트가 통과하였다(학생 배포본은 교수 폴더가 없어 1개를 건너뛰고 36개). 키트 저장소에서 CRLF로 꺼낸 사본에서도 같았다. 줄 끝을 확인하는 테스트는 `test_writes_lf_line_endings`, `test_report_uses_lf_line_endings`이다.

## 개인 정보에 대하여

- `ch05/기록/`에는 비식별 기록만 둔다. 이름, 연락처, 학번, 학교 이름, 사는 곳을 적지 않는다.
- `check_pii.py --names`에 쓰는 이름 목록은 저장소 밖(홈 폴더)에 두고 커밋하지 않는다. 이름을 `echo`처럼 터미널 명령으로 넣지 않는다(명령 기록에 남는다). 공용 PC에서는 수업이 끝날 때, 개인 PC에서도 산출물을 제출한 뒤 지운다.
- 개인 실습 저장소는 비공개여야 한다. 공개 저장소라면 `ch05/기록/`을 커밋하지 않고 교수에게 알린다.
- `예시기록/`의 기록은 가상의 기록이다. 이것으로 만든 페르소나는 「수업용 예시 기록에 근거한 연습용」이라고 밝힌다.
