# 페르소나

> 이 양식을 `ch05/페르소나.md`로 복사한다. 페르소나 두 명을 쓴다. 페르소나의 ID(PS-1, PS-2)는 문제 정의와 6장의 명세서가 가리키므로 바꾸지 않는다. 「배경」부터 「공감 지도」까지 모든 항목 끝에 근거를 `[인터뷰_01:L12]` 형식으로 단다. 근거가 없는 추측은 끝에 `(가정)`을 붙여 「가정과 확인할 것」에 모은다.

## 작성 정보

- 유형: 정성 페르소나(연습용). 근거 기록 「2」건
- 근거 기록: 「인터뷰_01, 인터뷰_02」 (조에서 공유받은 기록이 있으면 함께 적는다)
- 한계: 같은 수업의 수강생 「2」명을 인터뷰한 결과이다. 대상 사용자 전체를 대표하지 않으며, 각 페르소나가 사용자의 몇 %인지 알 수 없다
- 이름과 얼굴: 이름은 가명이다. 사진을 넣지 않는다
- 작성: 「날짜」, Claude Code 초안을 작성자가 검토
- 검사: `check_trace.py` 결과 「통과/불통과」, 대조표 판정 「O 개, △ 개, X 개」
