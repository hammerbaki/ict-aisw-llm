# 교수가 실제 에이전트로 돌린 기록 (강의안 2-8, 6-9, 7-3)

학습자는 6-9에서 자기 계정으로 루프를 한 번 돌린다. 교수는 수업 전에 같은 루프를 돌려 그 기록을 키트 저장소의 이 폴더에 올린다. 계정 문제로 6-9를 돌리지 못한 학습자는 이 기록으로 같은 확인을 한다. 2-8의 `stream-json`과 7-3의 실제 요약은 교수 시연이며, 그 결과도 이 폴더에 둔다. `git -C ~/kits-repo pull` 뒤 `cp -rn ~/kits-repo/Agent_08장/실습재료/시연기록 ~/kits/Agent_08장/실습재료/`로 받는다.

| 경로 | 내용 | 강의안 |
|---|---|---|
| `real-1/real-1.jsonl` | 루프의 JSON 줄 기록(start, judge, attempt, end) | 6-9 |
| `real-1/real-1/` | 시도마다 에이전트에게 넘긴 지시문(`attempt-N.prompt.md`)과 되돌린 시도의 diff | 6-9 |
| `real-1/최종변경.diff`, `real-1/최종변경_stat.txt`, `real-1/커밋.txt` | 루프 브랜치가 시작 커밋에서 바꾼 것 | 6-9 |
| `real-1/보고서.md` | 루프가 멈춘 경우에만 있다(사람 넘김 보고서) | 6-9 |
| `real-1/환경.txt` | 시연한 날짜와 Claude Code 버전 | 6-9 |
| `stream-2-8.txt` | (있으면) 2-8의 `stream-json` 사건 종류 목록 | 2-8 |
| `digest-2027-09-08.md` | (있으면) 실제 에이전트가 쓴 2027-09-08의 운영 요약 | 7-3 |

기록이 아직 없으면 수업 시간에 교수 화면으로 본다. 기록 안의 비용과 세션 아이디는 시연한 날의 값이며 실행마다 다르다.
