# 루프 설계서

- 대상 저장소: jobprep
- 작성: 「이름」, 「날짜」
- 루프 스크립트: `ops/loop/fix_until_green.py`

이 양식을 `docs/운영/루프설계서.md`로 복사해 채운다. 「 」 자리를 자기 결정과 근거로 바꾼다. 값만 적지 말고 그 값을 고른 까닭을 한 문장으로 붙인다.

## 1. 대상과 목표

| 항목 | 내용 |
|---|---|
| 루프로 돌리는 일 | 「예: 실패하는 테스트를 통과시키는 수정」 |
| 사람이 매번 돌리지 않는 까닭 | 「」 |
| 루프로 돌리지 않는 일(범위 밖) | 「예: 테스트를 새로 쓰는 일, 요구를 바꾸는 일」 |

## 2. 입력

| 항목 | 내용 |
|---|---|
| 루프가 시작하는 조건 | 「예: 작업 트리가 깨끗하고, 판정 명령이 실패(종료 코드 1, 2, 4)를 낸다」 |
| 에이전트에게 주는 것 | 「예: 지시문 틀 prompt_fix.md, 실패 출력의 요약, 앞선 시도의 처리 기록」 |
