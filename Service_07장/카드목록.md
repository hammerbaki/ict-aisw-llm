# 카드 소팅 카드 목록: 취업 준비 지원 서비스

- 카드 26장. 기능 카드(F)와 콘텐츠 카드(C)가 섞여 있다. 종류 표시는 참가자에게 보이지 않게 하고, 카드에는 번호와 이름, 설명만 적는다.
- 쓰는 법: 교수가 나눠 준 인쇄본을 오려 쓰거나, 종이에 번호와 이름을 옮겨 적는다. 화면에서 하려면 `카드소팅기록_양식.md`의 「묶음」 표에 카드 번호를 옮겨 적는다.
- 카드 이름은 명세서의 용어가 아니라 사용자가 알아볼 수 있는 말로 썼다. 묶음의 이름은 참가자가 짓는다(개방형).

## 진행 순서 (강의안 6-2, [선택] 짝 활동)

짝과 진행자와 참가자를 한 번씩 맡는다. 한 사람당 15분 안팎이다. 기록은 `카드소팅기록_양식.md`를 `ch07/카드소팅/기록_짝.md`로 복사해 쓴다.

1. **준비(2분).** 진행자는 인쇄 카드 26장을 섞어 책상에 펼친다. 인쇄본이 없으면 종이에 번호와 카드 이름을 옮겨 적는다. 위 표의 「종류」 열은 진행자만 본다.
2. **지시(1분).** 진행자는 다음 지시문을 그대로 읽는다. 지시문을 바꾸면 참가자의 분류가 달라진다.

   ```text
   이 카드들은 취업 준비를 돕는 서비스에 들어갈 기능과 내용입니다.
   비슷하다고 생각하는 것끼리 묶어 주세요. 묶음의 수와 크기는 자유입니다.
   묶음마다 이름을 붙여 주세요. 어디에도 안 맞는 카드는 따로 두셔도 됩니다.
   묶으면서 생각나는 것을 소리 내어 말해 주세요.
   ```

3. **분류(8분).** 참가자는 카드를 묶고, 진행자는 참가자의 말을 기록 양식의 「참가자의 말」 칸에 그대로 적는다. 진행자는 분류를 돕지 않는다. "이건 어디에 넣어야 해요?"에는 "어디에 넣고 싶으세요?"로 되돌린다.
4. **이름 붙이기와 되묻기(3분).** 묶음마다 이름을 받고, 망설인 카드가 있었다면 왜 망설였는지 묻는다.
5. **기록(1분).** 묶음마다 카드 번호를 양식에 적는다. 26장이 표에 한 번씩 모두 나오는지(빠진 카드, 두 번 들어간 카드가 없는지) 짝과 바꾸어 센다.

역할을 바꾸어 한 번 더 한 뒤, 마지막 10분에 종이 트리 테스트(강의안 6-4)를 한다.
