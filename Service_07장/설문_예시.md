# 설문 예시: 실습실 자리 잡기 (지어낸 예시)

제목: 실습실 자리 잡기 설문 (2분)

안내: 졸업 프로젝트 조가 실습실 예약 서비스를 고치려고 묻습니다. 이름, 학번, 연락처는 받지 않습니다. 답은 조원 셋만 보고, 학기가 끝나면 지웁니다. 답하고 싶지 않은 문항은 건너뛰어도 됩니다.

| 번호 | 문항 | 보기 | 확인하려는 기록 |
|---|---|---|---|
| 1 | 지난 한 달에 학과 실습실을 몇 번 썼습니까? | 없음 / 1~2번 / 3~5번 / 6번 이상 | - |
| 2 | 그때 자리를 어떻게 잡았습니까? (모두 고르기) | 예약 앱 / 그냥 가서 앉음 / 단체방에서 물어봄 / 기타 | [논의_02:L6][논의_02:L12] |
| 3 | 예약 앱에서 가장 최근에 예약할 때, 원하는 시간을 어떻게 찾았습니까? | 바로 찾음 / 날짜를 여러 번 바꿔 찾음 / 찾지 못함 / 예약한 적 없음 | [논의_01:L6-L7] |
| 4 | 예약해 두고 쓰지 않은 적이 있습니까? | 없음 / 한 번 / 여러 번 / 예약한 적 없음 | [논의_01:L9] |
| 5 | (4번에서 있다고 답한 분) 그때 예약을 어떻게 했습니까? | 취소함 / 취소하려 했으나 하지 못함 / 그대로 둠 | [논의_01:L10] |
| 6 | 예약한 시간을 바꾸려고 한 적이 있습니까? 어떻게 했습니까? | 없음 / 취소하고 새로 잡음 / 포기함 | [논의_02:L9] |
