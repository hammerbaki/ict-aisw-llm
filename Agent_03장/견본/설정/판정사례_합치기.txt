# 실행(저장소 폴더에서, 가상 환경을 켠 뒤): K=~/kits/Agent_03장/견본/설정
#   python ops/rules/perm_sim.py --cases $K/판정사례_합치기.txt --settings $K/user.json $K/project.json $K/local.json

# 사용자 설정의 allow와 팀 설정의 ask가 같은 명령에 맞는다. ask가 allow보다 먼저 본다
Bash(git push origin main) => ask

# 개인 로컬 설정의 allow는 팀 설정의 deny를 풀지 못한다. deny는 어느 범위에 있든 이긴다
Read(.env) => deny

# 각 범위의 allow는 합쳐진다
Bash(python -m pytest -q) => allow
Bash(uvicorn api.main:app --port 8010) => allow
