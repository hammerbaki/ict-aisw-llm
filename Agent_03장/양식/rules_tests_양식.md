# tests/ 규칙

- 새 테스트에는 요구 마커를 붙인다. 새 파일은 맨 위에 `pytestmark = pytest.mark.req(id="REQ-…")`, 기존 파일에 더하는 함수에는 바로 위에 `@pytest.mark.req(id="REQ-…")`. 이유: 「」
- 「테스트가 도는 모드와 부르지 않는 것」
- 「API를 부르는 픽스처, 날짜를 고정하는 방법」
- 「LLM 실패를 흉내 내는 방법」
- 「경계값을 쓰는 방법」
