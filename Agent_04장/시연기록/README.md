# 시연기록 (Agent_04장, 10절)

4장 10절 「스킬 유무 비교」는 교수 시연으로 실행한다. 같은 요청을 조건마다 여러 번 실행해야 비교가 의미를 갖고, 반복 실행은 계정의 사용량을 많이 쓰기 때문이다(이 장의 실행 상한). 교수는 시연이 끝나면 키트 저장소의 이 폴더(`Agent_04장/시연기록/`)에 실행 기록을 커밋한다. 학습자는 `git -C ~/kits-repo pull`로 받아 `~/kits-repo/Agent_04장/시연기록/`에서 읽는다.

| 파일 | 내용 |
|---|---|
| `A_1.md` … `A_N.md` | 조건 A. 스킬을 모두 끈 헤드리스 실행(`claude -p --disable-slash-commands`)에 요청 문장만 보낸 결과 |
| `B_1.md` … `B_N.md` | 조건 B. 1단계 커맨드 `/incident-report 2027-09-08`의 결과 |
| `C_1.md` … `C_N.md` | 조건 C. 3단계 플러그인 스킬 `/jobprep-ops:incident-report 2027-09-08`의 결과 |
| `요약.tsv` | 회차마다 서식 검사의 첫 줄, `logs/` 근거 줄 수, 걸린 시간, 비용 추정 |
| `실행정보.md` | 실행한 날짜, Claude Code 판, 모델, 커밋, 요청 문장과 옵션 |
| `A_집필예시.md` | 교수가 기록을 올리기 전에 쓰는 대체물. 집필자가 조건 A 결과의 전형을 본떠 쓴 것이며, 모델을 실제로 불러 얻은 결과가 아니다 |

`claude -p --output-format json`의 원래 출력(`json/`)은 세션 ID와 교수 PC의 경로가 들어 있어 배포하지 않는다.

학습자는 이 폴더의 파일을 고치지 않는다. 강의안 10절의 명령으로 `A_1.md`(없으면 `A_집필예시.md`)를 자기 저장소의 `docs/운영/장애보고/비교_A.md`로 복사하고, 회차별 보고서 전체를 `check_report.py`로 검사한다.
