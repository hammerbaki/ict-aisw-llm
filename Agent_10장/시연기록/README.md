# 시연기록 (Agent_10장, 10-4절)

10장의 핵심 실습은 Orca의 작업 공간 둘에서 자기 계정의 Claude Code 대화형 세션 둘로 한다. 같은 ISSUE-07을 스크립트 조정자(`ops/multi/run_issue.sh`)가 실제 Claude Code를 무인으로 되풀이해 돌리는 실행은 이 장의 실행 상한을 넘으므로 교수 시연이다(편성표 결정 11). 교수는 수업 전에 시연 저장소에서 실행하고, 그 기록을 정리해 이 폴더의 `ISSUE-07/`에 올린다.

| 파일 | 내용 |
|---|---|
| `ISSUE-07/events.jsonl` | 실행 기록(누가 언제 무엇을 했는가). 한 줄에 사건 하나 |
| `ISSUE-07/판정_T*.md` | 시도마다의 판정. 판정한 커밋이 적혀 있다 |
| `ISSUE-07/T*_시도N.json` | 실제 Claude Code의 결과에서 필요한 필드만 남긴 것(`total_cost_usd`, `num_turns`, `is_error` 등) |
| `ISSUE-07/요약.md` | 시도마다의 종료 여부, 턴 수, 비용과 합계 |

홈 폴더 경로는 `~`로, 세션 식별자는 지웠다. 비용은 Claude Code가 계산한 추정값이며 실제 청구액과 다를 수 있다. 교수가 올리기 전에는 이 README만 있다. 학습자는 이 폴더의 파일을 고치지 않는다.
