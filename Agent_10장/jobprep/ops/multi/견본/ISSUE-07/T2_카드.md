## 목표

목록 화면(`web/index.html`)에 「관심 공고 내보내기」 단추를 두고, 누르면 관심 공고의 CSV 파일이 내려받아지게 한다.

## 계약

- API: `GET /api/favorites/export?ids=3,1`. 이 작업은 API를 만들지 않는다(T1이 만든다). 주소만 이 모양으로 만든다
- 관심 공고 번호는 `web/js/common.js`의 `loadFavorites()`로 읽는다. API 주소의 앞부분은 `API_BASE`를 쓴다
- 단추의 id는 `export-favorites`이다. 스크립트는 `web/js/export.js`에 두고, `index.html`에서 `common.js`, `list.js` 다음에 불러온다
- 관심 공고가 없으면 API를 부르지 않고 상태 줄(`statusBox`, `showStatus()`)에 「내보낼 관심 공고가 없다」를 알린다

## 하지 않는 것

- 소유 파일 밖의 파일을 고치지 않는다. 특히 `web/js/common.js`, `web/js/list.js`, `web/css/style.css`, `docs/요구사항명세서.md`는 고치지 않는다
- 화면에 글을 넣을 때 `innerHTML`을 쓰지 않는다(`el()`과 `textContent`)
- `tests/`의 파일을 고치지 않는다

- `docs/운영/변경기록.md`의 맨 끝에 다음 한 줄을 더했다(위의 줄은 고치지 않는다): `- ISSUE-07 T2: 목록 화면의 관심 공고 내보내기 단추 (REQ-FAV-05)`
