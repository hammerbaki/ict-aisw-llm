# 기준 산출물 (4장)

4장이 앞 장에서 받는 것은 개인 실습 저장소 `~/llm-service-lab` 하나다(2장에서 만들고 3장까지 쓴 것). 4장의 조사에는 1~3장의 내용 산출물이 필요하지 않다.

## 저장소가 없을 때

2장을 하지 못해 저장소가 없으면, 아래 명령으로 빈 저장소를 만들고 4장을 시작한다. GitHub 원격 연결과 푸시는 2장 0절과 부록 A를 따라 나중에 한다.

```bash
mkdir -p ~/llm-service-lab
cd ~/llm-service-lab
git init
git config user.name "「이름」"
git config user.email "「GitHub에 등록한 이메일」"
echo "# llm-service-lab" > README.md
git add README.md
git commit -m "저장소 시작"
```

## 4장의 결과를 받는 장

4장의 결과(`ch04/`의 다섯 파일)는 5장에서 쓴다. 4장을 끝내지 못한 학습자를 위한 4장의 견본은 5장 키트의 `기준산출물/ch04/`에 들어 있다.
