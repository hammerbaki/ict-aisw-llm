# 조사 프롬프트 견본 (4장)

Claude Code 입력 창에 그대로 붙여 쓴다. 「 」 안은 학습자가 바꿔 넣는 자리다. 모든 프롬프트는 저장소 루트(`~/llm-service-lab`)에서 실행한 Claude Code에 보낸다. 웹 검색(WebSearch)과 웹 페이지 읽기(WebFetch)를 처음 쓸 때 허용을 묻는다. 도메인을 확인하고 허용한다.

## P1. 조사 질문 다듬기 (웹 도구를 쓰지 않는다)

```text
ch04/시장조사.md의 2절 「조사 질문」 표를 검토하라. 공통 사례는 「취업 준비 지원 서비스」, 대상 사용자는 전문대학 2학년 취업 준비생이다.
각 질문마다 (1) 이 질문의 답으로 무엇을 결정하는가 (2) 2차 자료로 답할 수 있는가, 1차 자료(인터뷰·설문)가 필요한가 (3) 답이 수치라면 어떤 단위와 기준 시점이 필요한가를 표로 답하라.
질문을 새로 쓰지 말고 고칠 점만 제안하라. 파일은 고치지 말라.
```

## P2. 공공 통계 조사 (웹 검색과 웹 페이지 읽기)

```text
웹 검색과 웹 페이지 읽기 도구로 다음 조사 질문에 답할 공공 통계를 찾아라.
- 「Q1: 전문대학 졸업 학년 학생은 한 해에 몇 명인가」
- 「Q2: 전문대학 졸업자의 취업률과 첫 일자리까지 걸리는 기간」
규칙:
1. 자료는 공공 기관의 원문만 쓴다: 국가통계포털 KOSIS, 교육부·한국교육개발원의 교육통계, 고용노동부·한국고용정보원, 국가데이터처의 보도자료. 언론 기사, 블로그, 백과사전은 자료로 쓰지 않는다.
2. 수치마다 다음을 적는다: 값, 단위, 기준 시점, 대상(분모), 표 이름과 쪽, 원문 주소, 확인 날짜(이 작업을 한 날짜, YYYY-MM-DD), 원문에서 그 수치가 나오는 문장을 짧게 그대로 옮긴 인용.
3. 원문을 열어 수치를 확인하지 못했으면 그 수치를 쓰지 말고 "찾지 못함"이라고 적는다. 기억이나 추정으로 수치를 채우지 않는다.
4. 같은 항목에 기준 시점이 다른 값이 여럿 있으면 가장 최근 값을 쓰고, 다른 값은 따로 적는다.
5. 결과는 ch04/시장조사.md의 4-1절 표와 10절 출처 표의 형식으로 써 넣는다. 다른 절은 고치지 않는다.
끝나면 찾은 수치와 찾지 못한 질문을 목록으로 보고하라.
```

## P3. 경쟁 서비스의 기능 관찰

```text
다음 다섯 서비스의 공식 누리집 첫 화면과 전체 메뉴를 웹 페이지 읽기 도구로 읽어라: 「사람인 https://www.saramin.co.kr/zf_user/, 잡코리아 https://www.jobkorea.co.kr/, 링커리어 https://linkareer.com/, 자소설닷컴 https://jasoseol.com/, 고용24 https://www.work24.go.kr/」
규칙:
1. 페이지에 글자로 나타난 메뉴와 기능만 쓴다. 페이지에 없는 기능을 상식이나 기억으로 채우지 않는다.
2. 서비스마다 관찰한 메뉴 이름을 페이지의 표기 그대로 옮긴다.
3. 기능을 사용자의 업무 단위(공고 찾기, 일정 챙기기, 서류 쓰기 등)로 묶어 10행 이상의 비교표를 만든다.
4. 칸에는 ○(확인됨), △(일부·조건부), -(확인되지 않음)만 쓴다. "없음"이라고 쓰지 않는다. 첫 화면에서 보이지 않았다는 것은 없다는 뜻이 아니다.
5. 결과는 ch04/경쟁서비스_비교표.md의 양식(1절 비교표, 2절 근거 표)에 써 넣고, 관찰 날짜는 이 작업을 한 날짜(YYYY-MM-DD)로 적는다.
읽지 못한 페이지가 있으면 그 사실을 보고하라.
```

## P4. 초안의 자기 점검 (근거 인용 요구)

```text
ch04/시장조사.md의 수치를 하나씩 검토하라. 수치마다 출처 표의 주소를 다시 열어, 그 수치를 뒷받침하는 문장을 원문에서 그대로 찾아 인용하라.
뒷받침하는 문장을 찾지 못한 수치는 고치지 말고, 그 수치 뒤에 [근거 못 찾음]을 붙여라.
기준 시점, 단위, 대상(분모)이 원문과 다른 수치는 [불일치: 이유]를 붙여라.
끝나면 [근거 못 찾음]과 [불일치]의 목록을 보고하라. 수치를 새로 추가하지 말라.
```

## P5. 포지셔닝 점수와 그림

```text
ch04/경쟁서비스_비교표.md의 비교표를 근거로 ch04/포지셔닝.md를 채워라.
가로축은 「대상의 범위(전 연령·경력 → 전문대학 졸업 학년 전용)」, 세로축은 「지원의 방식(정보 제공 → 실행 지원)」이다.
1. 세로 점수는 비교표의 「실행 지원 6행: 공고 스크랩·마감 알림, 이력서 작성·관리, 자기소개서 작성 도구, AI 서류·자기소개서 코칭, AI 모의면접, 지원 현황 관리」에서 ○ 1점, △ 0.5점의 합을 6으로 나누어 계산하고 계산식을 남긴다.
2. 가로 점수는 포지셔닝.md 1절의 점수 규칙에 따라 정하고, 서비스마다 근거가 된 메뉴 이름을 적는다.
3. 그림은 mermaid quadrantChart로 그리고, 공통 사례의 목표 위치를 점 하나로 더한다.
비교표에 없는 정보로 점수를 정하지 말라.
```

## P6. 가치 제안 캔버스 초안

```text
ch04/시장조사.md와 ch04/경쟁서비스_비교표.md를 읽고 ch04/가치제안.md의 양식을 채워라.
1. 고객 업무는 기능, 사회, 감정의 세 종류를 모두 포함한다.
2. 「확인 근거」 열에는 두 파일의 출처 기호나 비교표의 행 이름만 쓴다. 근거가 없으면 비워 둔다. 근거를 지어내지 않는다.
3. 가치 제안 문장은 양식의 문형 하나로 쓴다.
4. 비어 있는 확인 근거는 5장에서 인터뷰로 확인할 목록으로 5절에 옮긴다.
```
