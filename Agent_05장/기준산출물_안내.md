# 기준산출물 안내 (5장)

3장 또는 4장을 마치지 못한 학습자를 위한 견본이다. 앞 장을 마친 학습자는 쓰지 않는다. 정합 기준 v1.0의 3절에 따라 4장의 결과(3장 교수 완성본의 팀 규칙과 권한, 4장의 플러그인)를 그대로 복사하였다.

| 파일 | 앞 장 | 출처와 내용 |
|---|---|---|
| `기준산출물/CLAUDE.md` | 3장 | 3장 `교수/완성본/팀_CLAUDE.md`. 실행 명령, 작업 규칙, 금지 |
| `기준산출물/.claude/rules/api.md`, `tests.md` | 3장 | 3장 `교수/완성본/rules_api.md`, `rules_tests.md`(경로별 규칙) |
| `기준산출물/.claude/settings.json` | 3장 | 3장 `교수/완성본/settings.json`. 테스트·동결 검사·커밋 허용, `git push`·설정 파일 편집 확인, `.env` 읽기와 `data/`·동결 기록 편집 거부. `logs/` 편집 거부는 없다(9-8절에서 더한다) |
| `기준산출물/plugins/jobprep-ops/` | 4장 | 4장 `예비/`(plugin.json 0.1.0, README, SKILL.md)와 `재료/incident-report/`(references, scripts)를 4장 본문의 배치대로 놓았다. 5장 9-10절에서 읽기만 한다 |
| `기준산출물/.claude-plugin/marketplace.json` | 4장 | 4장 `예비/marketplace.json`(마켓플레이스 `jobprep-team`) |

4장의 테스트(`tests/test_ops_skill.py`, `tests/test_ops_plugin.py`)는 넣지 않았다. 넣으려면 4장 키트의 `tests/`에서 복사한다.

## 넣는 법

저장소 폴더에서 실행한다. `cp -rn`은 이미 있는 파일을 덮어쓰지 않는다.

```bash
cd ~/agent-lab/jobprep
cp -rn ~/kits/Agent_05장/기준산출물/. .
git add CLAUDE.md .claude .claude-plugin plugins
git commit -m "chore: 3·4장 기준산출물 반영(팀 규칙, 권한, jobprep-ops 플러그인)"
```

`.claude/settings.json`에 `logs/` 편집 거부(`Edit(/logs/**)`)가 없으면, 9-8절의 `merge_settings.py`가 더해 준다.
