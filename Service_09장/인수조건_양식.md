# 인수 조건: 공고 모아보기 웹 (9장)

> 이 양식을 `jobprep/docs/인수조건.md`로 복사해 쓴다. 명세의 요구 하나에 인수 조건 하나 이상을 둔다.
> 번호는 `AC-<요구 번호 세 자리>-<순번>`이다(예: REQ-007의 두 번째 인수 조건은 AC-007-2). 명세서 6절의 수용 기준 `AC-NNN-1`을 이 장의 공고 자료로 구체화한 것은 같은 번호를 쓰고, 이 장에서 더한 것은 다음 순번을 쓴다.
> 이 표에는 이 장에서 구현하는 요구만 둔다. 구현하지 않는 요구(REQ-005, REQ-011, REQ-012, 10~11장의 LLM 기능 등)는 `작업목록.md`의 「이 판에서 구현하지 않는 요구」에 적는다.
> 확인 방법: 「자동(브라우저)」은 `check/check_browser.py`, 「자동(정적)」은 `check/check_static.py`, 「손 점검」은 사람이 화면에서 한다.

## 기준

- 명세 판: 「v3」, 화면 명세 판: 「v3, 검사용 약속 포함」
- 검사한 날: 「YYYY-MM-DD」, 검사한 커밋: 「해시 7자리」
- 검사 환경: 「브라우저와 판, 화면 폭」
