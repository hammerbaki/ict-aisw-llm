
## 웹 구현 규칙 (9장)

- 웹은 `web/`에 있고 빌드 도구 없이 HTML, CSS, 자바스크립트만 쓴다.
- 외부 주소(CDN, 웹 글꼴, 분석 도구)를 부르지 않는다. 모든 경로는 상대 경로다.
- 색, 글꼴, 간격은 `web/css/tokens.css`의 변수만 쓴다.
- 화면에 자료나 사용자 입력을 넣을 때 `innerHTML`을 쓰지 않고 `textContent`를 쓴다.
- 브라우저 저장소의 키는 화면 명세 「검사용 약속」의 표를 따른다(`jobprep:` 접두사).
- `web/check/`와 `tools/`는 고치지 않는다. 검사가 틀렸다고 판단되면 고치지 말고 알린다.
- 작업이 끝나면 `python web/check/check_static.py`를 실행해 결과의 마지막 줄을 보인다(가상 환경을 켠 터미널에서 Claude Code를 실행한 것을 전제로 한다).
