# 접근성 점검: jobprep 프로토타입

- 점검 대상: `prototype/` (8장 정답 예시)
- 점검한 사람과 날짜: 집필자, 2026-11-14(정합 작업에서 화면 요소를 명세서 v3에 맞춘 뒤 자동 점검을 다시 하였다)
- 기준: 명세서 v3의 REQ-033~036과 WCAG 2.2 수준 AA 중 아래 표의 성공 기준. 전체 적합성 평가가 아니라 프로토타입 단계의 기본 점검이다.
- 브라우저: Microsoft Edge 157(Playwright 1.64로 구동), 화면 폭 1280px과 320px

## 4. 점검하지 못한 것

- 화면 낭독기(NVDA, 내레이터, VoiceOver)로 읽어 본 결과. 상태 영역이 실제로 읽히는지는 9장 구현 뒤 확인한다.
