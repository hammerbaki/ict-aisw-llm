## SCR-0N. 「화면 이름」

### 1) 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | SCR-0N |
| 목적 | 「이 화면에서 사용자가 끝내는 일 한 문장」 |
| 관련 요구 | 「REQ-0xx, REQ-0yy」 |
| 들어오는 길 | 「어느 화면의 무엇을 눌러서」 |
| 나가는 길 | 「무엇을 누르면 어느 화면으로」 |
| 사용자 흐름 | 「FLOW-01의 몇 번째 단계」 |

### 2) 와이어프레임

모바일(좁은 화면) 배치를 먼저 그리고, 넓은 화면에서 달라지는 점을 아래에 적는다.

```text
「ASCII 와이어프레임」
```

넓은 화면(「중단점」 이상): 「무엇이 몇 열로 바뀌는가」
