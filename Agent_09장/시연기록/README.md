# 교수 시연의 실행 기록 (강의안 7-9, 10-4)

실제 모델(API 키)로 에이전트 루프와 Agent SDK 판을 돌리는 단계는 교수가 시연한다. 교수는 수업 전에 그 기록을 키트 저장소의 이 폴더에 올린다. 이 장의 실행 상한은 「모의 모델이 기본. 실제 API는 각자 키가 있으면 1회」이다. 키가 없는 학습자는 `git -C ~/kits-repo pull` 뒤 이 기록으로 같은 확인을 한다.

| 파일 | 내용 | 강의안 |
|---|---|---|
| `real.json` | `agent_loop.loop --save`가 남긴 대화 기록과 회차 기록(`system`, `tools`, `messages`, `log`, `stop`). 저장소의 `agent_loop/runs/real.json`으로 복사해 읽는다 | 7-9, 8-2 |
| `real_출력.txt` | 같은 실행의 화면 출력 | 7-9 |
| `sdk_출력.txt` | `agent_loop.sdk_agent`의 화면 출력(도구 요청, 훅, 결과, 최종 답) | 10-4 |
| `환경.txt` | 시연한 날짜, 모델 이름(`LLM_MODEL`), 패키지 판 | 7-9, 10-4 |

기록이 아직 없으면 수업 시간에 교수 화면으로 본다. 토큰 수, 비용, 회차 수는 시연한 날의 값이며 실행마다 다르다. 이 폴더에 API 키는 들어 있지 않다.
