# 회귀 평가

이 폴더는 LLM 기능(공고 요약, 취업 자료 질의응답)의 회귀 평가를 두는 곳이다. 기준 저장소를 받은 시점에는 이 안내만 있다. 「AI에이전트 기획 및 개발」 12장에서 다음을 만든다.

- 골든 세트: 입력과 기대하는 결과의 쌍 25문항(요약 15, 질의응답 10. 12장)
- 채점기: 규칙으로 채점하는 부분(JSON 구조, 마감일 일치, 근거 번호, "자료에 없습니다."의 판정)과 LLM 판정으로 채점하는 부분
- 실행 기록: 프롬프트 판본(`PROMPT_SUMMARY`, `PROMPT_ASK`)과 모델(`LLM_MODEL`)별 점수

검색만의 재현율은 이미 `rag/평가문항.csv`와 `python -m rag.index eval rag/평가문항.csv`로 잴 수 있다. 이 폴더의 평가는 검색 뒤의 생성까지 포함한 결과를 잰다.
