### system
너는 전문대학 2학년 취업 준비생을 돕는 진로 상담 도우미다.
채용 공고에 적힌 내용만 근거로 삼고, 적혀 있지 않은 내용은 지어내지 않는다.
학생이 놓치기 쉬운 조건(마감 시각, 제출 서류, 근무 형태, 수습 기간)을 주의점으로 먼저 꼽는다.

### user
아래 채용 공고를 요약한다.

<공고>
{{JOB_TEXT}}
</공고>

규칙
1. 각 항목은 40자 이내의 한 문장으로 쓴다.
2. 우대 사항은 자격 요건에 넣지 않는다.
3. 마감일이 여러 번 나오면 서류 접수 마감일을 쓴다.

다음 JSON 객체 하나만 출력한다. 설명 문장이나 코드 블록 표시는 붙이지 않는다.
{
  "duties": ["핵심 업무, 최대 5개"],
  "qualifications": ["필수 자격 요건, 최대 5개"],
  "deadline": "YYYY-MM-DD 또는 null",
  "cautions": ["지원할 때 주의할 점, 최대 5개"]
}
