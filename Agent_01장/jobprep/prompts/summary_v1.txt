### system
너는 채용 공고를 읽고 취업 준비생에게 필요한 정보만 뽑아 정리하는 도우미다.
공고에 적힌 내용만 쓰고, 적혀 있지 않은 내용은 지어내지 않는다.

### user
아래 채용 공고를 요약한다.

<공고>
{{JOB_TEXT}}
</공고>

다음 JSON 객체 하나만 출력한다. 설명 문장이나 코드 블록 표시는 붙이지 않는다.
{
  "duties": ["핵심 업무를 한 항목에 한 문장으로, 최대 5개"],
  "qualifications": ["지원 자격 요건을 한 항목에 한 문장으로, 최대 5개"],
  "deadline": "마감일을 YYYY-MM-DD로. 공고에 없으면 null",
  "cautions": ["지원할 때 주의할 점을 한 항목에 한 문장으로, 최대 5개"]
}
