# 운영 문서

이 폴더에는 `jobprep`을 운영하며 만드는 문서를 둔다. 기준 저장소를 받은 시점에는 이 안내만 있다. 「AI에이전트 기획 및 개발」의 각 장이 아래 문서를 하나씩 더한다.

| 장 | 이 폴더에 더하는 문서 |
|---|---|
| 1 | `운영요건.md`(EARS로 쓴 운영 요건과 측정 방법), `역할정의.md`(운영 에이전트 시스템의 역할 초안) |
| 3 | `저장소규약.md`, `규칙비교.md` |
| 4 | `스킬비교.md` |
| 5 | `MCP점검.md` |
| 6 | `검토자검증.md` |
| 7 | `하네스설계서.md`, `하네스비교.md` |
| 8 | `루프설계서.md` |
| 10 | `멀티에이전트설계.md`, 인계 문서 |
| 11 | `위협모델.md` |
| 12 | `평가보고.md` |
| 13 | `배포점검표.md`, `운영요건지도.md` |

서비스의 기능 요구는 `docs/요구사항명세서.md`에 있다. 운영 문서는 그 요구를 운영 중에 어떻게 지키고 확인하는지를 다룬다.
