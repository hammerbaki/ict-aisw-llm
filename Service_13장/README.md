## 도구 실행과 테스트

파이썬 3.12 이상. `priority.py`는 표준 라이브러리만 쓴다. 테스트에만 pytest가 필요하다. 가상 환경을 켠 터미널에서 실행한다(부록 A-13).

```bash
cd ~/kits/Service_13장/도구
python -m pip install -r requirements.txt
python -m pytest -q tests
python priority.py 예시/문제목록_예시.csv
```

## 견본을 열기

```bash
python -m http.server 8100 --bind 127.0.0.1 --directory ~/kits/Service_13장/연습견본/web       # 4-3 연습
python -m http.server 8100 --bind 127.0.0.1 --directory ~/kits/Service_13장/기준산출물/ch05/web # 서비스 1 견본
```

두 견본 모두 같은 8100을 쓰므로 하나씩 띄우고, 견본을 바꿀 때마다 시크릿 창을 새로 연다. 두 견본에는 평가 실습을 위해 사용성 문제를 일부러 남겨 두었다. 평가하기 전에 코드를 읽지 않는다.
