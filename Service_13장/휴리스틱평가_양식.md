## 2. 절차 (괄호 앞은 권장 시간, 뒤는 4-3 연습의 시간)

1. 첫 번째 훑기(5분 / 2분): 판단하지 않고 과업을 한 번 해 본다. 제품이 무엇을 하는지 익힌다.
2. 두 번째 훑기(15분 / 3분): 같은 과업을 다시 하며 휴리스틱 H1~H10과 AI 점검 항목 A1~A6에 어긋나는 곳을 아래 표에 적는다. 빈 값을 넣고, 단추를 빠르게 두 번 누르고, 창을 좁혀 본다.
3. 마무리(5분 / 1분): 각 문제에 심각도(0~4)를 매긴다. 심각도 기준은 `심각도기준표.md`를 본다.

## 4. 휴리스틱 번호표 (Nielsen, 1994/2024)

| 번호 | 휴리스틱 |
|---|---|
| H1 | 시스템 상태의 가시성 |
| H2 | 시스템과 현실 세계의 일치 |
| H3 | 사용자 통제와 자유 |
| H4 | 일관성과 표준 |
| H5 | 오류 예방 |
| H6 | 기억보다 인식 |
| H7 | 사용의 유연성과 효율성 |
| H8 | 미적이고 최소한의 디자인 |
| H9 | 오류의 인식, 진단, 회복 지원 |
| H10 | 도움말과 문서 |

## 5. AI 기능 점검 항목 (교재 5절)

AI 기능(공고 요약, 자기소개서 피드백, 취업 자료 질문)이 있는 화면에서 다음을 함께 본다. 어긋나면 3절 표의 「휴리스틱」 칸에 A 번호를 적는다.

| 번호 | 점검 항목 | 근거 |
|---|---|---|
| A1 | 기능이 무엇을 할 수 있고 무엇을 못 하는지 화면이 알려 주는가 (기대 설정) | HAX G1, PAIR 정신 모형 |
| A2 | 결과가 틀릴 수 있음을 알려 주는가, 과장된 약속은 없는가 | HAX G2 |
| A3 | 만드는 동안 진행 상태가 보이는가, 중복 요청이 막히는가 | H1, H5 |
| A4 | 결과의 근거(원문의 어느 부분, 어느 자료)를 확인할 수 있는가 | HAX G11, NN/g 일지 연구 |
| A5 | 결과가 마음에 들지 않을 때 다시 생성, 수정, 부분 수정의 길이 있는가 | HAX G9, NN/g 아코디언 편집 |
| A6 | 실패하거나 근거가 없을 때 이유와 다음에 할 일을 알려 주는가 | H9, HAX G10, PAIR 오류 |
