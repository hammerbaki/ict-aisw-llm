# 기준산출물: 서비스 1(공고 모아보기 웹)의 견본

5장의 산출물(`ch05/web/`, `ch05/인수조건.md`)이 없는 학습자가 13장의 평가 대상으로 쓰는 최소 견본이다. **공고 열 건과 명세의 근거는 모두 지어낸 것이다.** 실제 회사나 실제 공고가 아니며, 고용24에서 받은 자료도 아니다. 자료 파일의 꼴만 5장의 `xml2json.py`가 만드는 것과 같다.

| 경로 | 내용 |
|---|---|
| `ch04/요구사항명세서.md` | 요구 10개(REQ-01~10)와 수용 기준. 5장을 마친 상태(REQ-10까지)이다 |
| `ch05/인수조건.md` | 인수 조건 열 행. 「내 판정」은 견본을 만든 사람이 점검한 결과이다 |
| `ch05/web/` | 정적 웹(`index.html`, `style.css`, `app.js`, `data/jobs.json`) |

## 내 실습 저장소로 복사하기

5장 산출물이 없을 때만 한다. `-n`은 이미 있는 파일을 덮어쓰지 않는다.

```bash
cd ~/llm-service-lab
cp -rn ~/kits/Service_13장/기준산출물/ch04 ~/kits/Service_13장/기준산출물/ch05 .
ls ch05/web ch05/인수조건.md
```

## 열기

```bash
python -m http.server 8100 --bind 127.0.0.1 --directory ch05/web
```

브라우저의 시크릿 창에서 `http://localhost:8100/`을 연다. 서버를 끄려면 `Ctrl+C`를 누른다.

- **기준일.** 「마감 임박 D-N」은 기준일로부터 센다. 견본은 자료를 받은 날(2027-05-17)을 기준일로 쓰므로, 언제 열어도 같은 화면이 나온다. 다른 날로 보려면 주소 뒤에 `?today=2027-05-20`처럼 붙인다.
- 이 견본에는 평가 실습을 위해 사용성 문제를 일부러 남겨 두었다. 인수 조건은 모두 통과한다. 평가하기 전에 `app.js`를 읽지 않는다. 코드에서 찾은 문제는 사용자가 겪는 문제와 다를 수 있다.
