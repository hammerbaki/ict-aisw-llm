# 화면 명세: 잡프렙 (13장 평가용 견본, 발췌)

8장 화면 명세의 형식을 줄였다. 각 화면의 목적, 구성 요소, 상태를 적는다.

## SCR-01 공고 목록

- 목적: 마감이 가까운 공고를 훑어보고, 관심 공고를 요약하거나 지원 일정에 저장한다. (REQ-001~005, REQ-007)
- 구성: 검색 칸과 검색 버튼, 지역 선택과 적용 버튼, 공고 카드 목록, 요약 결과 상자
- 공고 카드: 회사명, 직무명, 지역, 마감일과 남은 날 수, 요약 버튼, 저장 버튼
- 상태
  - 기본: 전체 공고
  - 결과 없음: (정하지 않음)
  - 요약 중: (정하지 않음)

## SCR-03 지원 일정

- 목적: 지원할 공고의 마감일과 메모를 관리한다. (REQ-005, REQ-006, REQ-010)
- 구성: 입력 양식(회사, 마감일, 메모, 추가 버튼), 일정 목록(항목마다 삭제 버튼)
- 상태
  - 빈 목록: (정하지 않음)

## SCR-06 취업 자료 질의응답(탭 이름 「자료 묻기」)

- 목적: 학과 취업 자료에 대한 질문에 답한다. (REQ-008, REQ-009)
- 구성: 안내 문구, 질문 칸, 보내기 버튼, 답변 상자
- 상태
  - 답변 중: (정하지 않음)
  - 근거 없음: 자료에 없다고 답한다 (REQ-009)
