# jobprep (13장 평가용 견본)

앞 장(9~12장)의 `jobprep/`이 없는 학습자가 13장의 평가 대상으로 쓰는 작은 웹 프로토타입이다.
서버 없이 정적 파일로 돈다. AI 기능(공고 요약, 취업 자료 질문)은 실제 모델을 부르지 않고 정해진 규칙으로 흉내 낸다.

## 실행

```bash
python -m http.server 8100 --bind 127.0.0.1 --directory web
```

`jobprep` 폴더에서 실행하고, 내 PC의 브라우저(시크릿 창)에서 `http://localhost:8100/`을 연다(부록 A-16). 서버를 끄려면 `Ctrl+C`를 누른다.

## 들어 있는 것

| 경로 | 내용 |
|---|---|
| `web/` | 화면 세 개(공고 목록, 지원 일정, 자료 묻기). `index.html`, `style.css`, `data.js`, `app.js` |
| `docs/요구사항명세서.md` | 요구 ID(REQ-001~013)가 붙은 명세서 발췌 |
| `docs/설계/화면명세.md` | 화면 ID(SCR-)가 붙은 화면 명세 발췌 |

이 견본에는 평가 실습을 위해 사용성 문제를 일부러 남겨 두었다. 평가하기 전에 코드를 읽지 않는다. 코드에서 찾은 문제는 사용자가 겪는 문제와 다를 수 있다.
