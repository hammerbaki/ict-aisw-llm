# 프롬프트 판본 비교 (10장) — 기준 산출물 견본

10장 키트의 교수 예시 답안(모의 모드 결과로 채운 것)을 복사한 견본이다. 10장의 비교 기록이 없는 학습자가 11장을 진행하기 위한 것이다.

## 1. 고정한 조건

| 항목 | 값 |
|---|---|
| 평가 문항 | eval/공고 10건, eval/정답.json |
| 채점기 | eval/grader.py (판본 1.0) |
| 모델 | 모의 응답 재생(실제 모델 출력 아님) |
| 형식 강제 | 아니오(프롬프트만) |
| 실행 일시 | 2026-11-14 |

## 2. 결과

| 판본 | JSON | 형식 | 마감일 | 자격 | 근거 | 합계 | 평균 입력 토큰 | 평균 출력 토큰 | 1,000건 비용(USD) |

## 3. 판본마다 바꾼 것과 결과의 변화

| 판본 | 바꾼 것(한 가지) | 점수 변화 | 변화가 나타난 문항과 항목 |
|---|---|---|---|
| v1 | 기준선 | - | 코드 울타리·설명 문장(P01, P03, P07, P10)으로 JSON 실패 4건, 키 이름 제각각 |
| v2 | 규칙, 필드 정의, 근거 제한, 출력 형식 | +25 | 키 이름이 통일됨. P05의 '합격 보장' 사라짐. P07은 지시를 어기고 코드 울타리 |
| v3 | 예시 두 건(면접일 함께, 상시 채용) | +7 | P04 마감일, P03 null이 맞음. P07 형식도 맞음 |

## 4. 응답 원문으로 확인한 오답 두 건

- P04, v2: 마감일 "2027-06-21"은 [전형 일정]의 면접일이다. 접수 기간의 끝 날짜(2027-06-14)를 골라야 한다.
- P08, v3: 자격요건에 "정보처리기능사 보유자"가 들어갔다. 공고에서는 [우대 사항]이다.

## 5. 채택

- 채택 판본: v3
- 근거(점수): 49/50으로 가장 높고, 마감일 항목이 10/10이다(마감일은 지원 여부를 바꾸는 필드).
- 근거(비용): 1,000건 비용 0.1730달러, 월 3만 6천 건이면 약 6.23달러. v2보다 월 약 1.3달러 더 들지만 마감일 오류 두 건이 없어진다.
- 남은 문제와 다음 판본에서 바꿀 한 가지: 우대 사항이 자격요건에 섞이는 문제(P08). v4에서 규칙 3에 "[우대 사항] 칸의 내용은 어느 필드에도 쓰지 않는다"를 더한다.
- `.env`의 `PROMPT_VERSION`을 채택 판본으로 바꾸었는가: 예(v3)

## 6. 이 결과의 한계

- 모의 응답을 재생한 결과이므로 모델의 실제 성능이 아니다. 키가 발급되면 `LLM_FAKE=0`으로 같은 명령을 다시 실행해 실제 점수를 적는다.
- 실제 호출 결과도 한 번의 실행이다. 같은 판본을 세 번 실행해 점수의 흔들림을 본 뒤 채택한다.
