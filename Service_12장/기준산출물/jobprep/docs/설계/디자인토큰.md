# 디자인 토큰: 취업 준비 지원 서비스(jobprep)

- 판: v1.0 (8장 정답. 견본 v0.1에서 `color-text-muted`를 고쳤다)
- 원본: 이 파일이 토큰의 유일한 원본이다. `prototype/css/tokens.css`는 `tools/tokens_to_css.py`가 이 파일에서 만든다.
- 형식: 표 한 줄이 토큰 하나다. 첫 칸은 이름, 둘째 칸은 값이며 둘 다 백틱으로 감싼다. 값에서 다른 토큰을 `{이름}`으로 가리킬 수 있다(W3C 디자인 토큰 형식의 별칭 문법).
- 계층: 기본 토큰(값 자체)과 의미 토큰(용도. 기본 토큰을 가리킨다)의 두 층으로 둔다. 화면의 CSS는 의미 토큰만 쓴다.

## 3. 간격

8px을 한 단위로 하고, 촘촘한 자리에만 4px을 쓴다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `space-1` | `0.25rem` | 4px. 아이콘과 글자 사이 |
| `space-2` | `0.5rem` | 8px. 레이블과 입력 칸 사이 |
| `space-3` | `1rem` | 16px. 카드 안쪽 여백, 모바일 화면 여백 |
| `space-4` | `1.5rem` | 24px. 카드 사이, 입력 항목 사이 |
| `space-5` | `2rem` | 32px. 절 사이 |
| `space-6` | `3rem` | 48px. 화면 머리와 본문 사이 |

## 4. 모양과 크기

| 토큰 | 값 | 용도 |
|---|---|---|
| `radius-control` | `0.375rem` | 버튼, 입력 칸의 모서리 6px |
| `radius-card` | `0.75rem` | 카드의 모서리 12px |
| `size-target-min` | `2.75rem` | 누를 수 있는 요소의 최소 높이 44px(WCAG 2.5.8의 24px보다 넉넉하게) |
| `focus-ring-width` | `3px` | 초점 표시 테두리 두께 |
| `content-max-width` | `72rem` | 본문의 최대 폭 1152px |

## 5. 대비 쌍

전경 색과 배경 색의 쌍마다 기준을 적는다. 글자는 4.5(WCAG 1.4.3), 입력 칸 테두리와 초점 표시처럼 글자가 아닌 UI 요소는 3(WCAG 1.4.11)이다. `tools/contrast.py`가 이 표를 읽어 판정한다.

| 전경 | 배경 | 기준 | 용도 |
|---|---|---|---|
| `color-text` | `color-bg` | 4.5 | 본문 |
| `color-text` | `color-surface` | 4.5 | 카드 안 본문 |
| `color-text-muted` | `color-bg` | 4.5 | 보조 글자 |
| `color-text-muted` | `color-surface` | 4.5 | 카드 안 보조 글자 |
| `color-primary` | `color-bg` | 4.5 | 링크 |
| `color-on-primary` | `color-primary` | 4.5 | 주 버튼 글자 |
| `color-primary` | `color-primary-soft` | 4.5 | 선택된 필터 글자 |
| `color-danger` | `color-bg` | 4.5 | 입력 칸 아래 오류 문장 |
| `color-danger` | `color-danger-soft` | 4.5 | 오류 요약 상자 |
| `color-success` | `color-success-soft` | 4.5 | 저장 완료 알림 |
| `color-warning` | `color-warning-soft` | 4.5 | 마감 임박 표시 |
| `color-border-input` | `color-bg` | 3 | 입력 칸 테두리 |
| `color-focus` | `color-bg` | 3 | 초점 표시 |
| `color-focus` | `color-surface` | 3 | 카드 위 초점 표시 |
