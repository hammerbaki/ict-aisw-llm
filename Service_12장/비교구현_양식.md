# 비교 구현: 자기소개서 피드백 (variant-form과 variant-chat)

> 복사해 `jobprep/docs/비교구현.md`로 쓴다. 모든 칸은 측정이나 관찰로 채우고, 값 옆에 그 값을 낸 명령이나 파일을 적는다. 모의 모드의 값은 「모의」라고 밝힌다.

## 1. 비교 조건

| 항목 | 값 |
|---|---|
| 기준 명세 | `docs/요구사항명세서.md` 「자기소개서 피드백」 절, 태그 「spec-v7」 |
| 변형 브랜치와 커밋 | variant-form 「커밋」, variant-chat 「커밋」 |
| 같은 지시 | `docs/변형지시/공통.md` + 변형별 파일, 변형마다 새 세션 |
| 작업 공간 | Orca 「판」의 작업 공간 둘(Branch from 「spec-v7」) |
| 측정 환경 | 내 PC 「운영체제」, 서버 둘(form 8000, chat 8001), 모의 모드 「LLM_FAKE=1, LLM_FAKE_LATENCY=on」 |
| 과업(시나리오) | `시나리오/form.json`(요청 2회), `시나리오/chat.json`(요청 3회) |
