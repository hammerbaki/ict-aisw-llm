# API 코드 규칙

- 질의 매개변수와 요청 본문의 검증은 FastAPI의 검증(`Query`, pydantic 모델)으로 하고, 실패는 422로 응답한다.
- 기록기 이름은 `jobprep.<영역>`이다. 기록 한 줄은 `logs/README.md`의 `이름=값` 형식을 따른다.
- 사용자 입력(질문, 공고 본문)은 기록하지 않는다. 필요하면 글자 수(`q_len`, `text_len`)만 남긴다.
- 엔드포인트나 질의 매개변수를 더하면 `README.md`의 실행 예와 명세서의 요구 행을 함께 고친다.
