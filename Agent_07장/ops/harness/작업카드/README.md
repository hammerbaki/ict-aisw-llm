# 작업 카드

하네스 유무 비교에 쓰는 같은 작업 세 건이다. 세 건은 종류가 다르다(기능 구현, 운영 문서, 운영 코드). 한 종류만 재면 그 종류에서 일하는 부품만 효과를 보이기 때문이다.

| 카드 | 종류 | 판정 도구 | 판정 항목 수 |
|---|---|---|---|
| T1 | 기능 구현: 고용 형태 필터(REQ-JOB-07) | `인수검사/test_t1_employment_type.py` | 6 |
| T2 | 운영 문서: 2027-09-11 질의응답 장애 보고서(`docs/운영/장애보고/2027-09-11.md`) | `인수검사/check_t2_report.py` | 10 |
| T3 | 운영 코드: 질의응답 운영 기록(REQ-OPS-07) | `인수검사/test_t3_ask_log.py` | 3 |

## 지키는 것

- 프롬프트는 각 카드의 「프롬프트」 절 본문을 그대로 보낸다. 실행 도중에 고쳐 쓰지 않는다. 고치면 두 조건이 같은 작업이 아니게 된다.
- 프롬프트에는 하네스가 알려 주는 규칙을 적지 않았다. 규칙을 프롬프트에 적으면 하네스가 없는 조건도 그 규칙을 받게 되어 하네스의 효과를 잴 수 없다.
- 인수 검사와 작업 카드는 실험 저장소에서 지운다(`prepare_runs.sh`가 한다). 에이전트가 정답 검사를 읽고 맞추는 것을 막기 위해서다.
