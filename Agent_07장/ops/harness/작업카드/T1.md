실행할 때는 아래 「프롬프트」 절의 본문만 Claude Code에 보낸다. 하네스가 있을 때와 없을 때 같은 글을 보낸다.

## 프롬프트

공고 목록 API(`GET /api/jobs`)에 고용 형태로 공고를 거르는 질의 매개변수 `employment_type`을 더하라.

- 값과 같은 고용 형태의 공고만 돌려준다. 값이 `계약직`이면 고용 형태가 `계약직`으로 시작하는 공고(예: `계약직(1년, 전환 검토)`)도 포함한다.
- 기존 조건(`field`, `q`)과 함께 쓸 수 있어야 한다.
- 빈 문자열이 오면 422로 응답한다.
- 요구 ID는 REQ-JOB-07이다.

테스트를 포함해 구현하고, 끝나면 무엇을 바꾸었는지 보고하라.
