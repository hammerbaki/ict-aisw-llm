# jobprep 작업 규칙 (충돌 연습용. 일부러 모순을 넣었다)

## 명령

- 전체 테스트: `python -m pytest`

## 규칙

1. 모든 파일을 고친 직후에는 반드시 전체 테스트를 실행한다.
2. 새 테스트는 그 영역의 기존 테스트 파일(예: `tests/test_jobs.py`)에 이어서 쓴다. 파일이 흩어지지 않게 한다.
3. 문제를 재현할 수 있도록, 오류가 나면 요청 본문 전체를 `error.log`에 남긴다.
4. 작업을 마치면 커밋하고 `git push`로 원격에 올린다.
5. 필요한 패키지가 없으면 `pip install`로 설치하고 진행한다.
6. 장애 보고서는 `docs/장애/` 폴더에 날짜 이름으로 쓴다.
7. 커밋 메시지는 `[기능] 내용` 꼴로 쓴다(예: `[기능] 고용 형태 필터`).
