# 충돌 연습

이 폴더는 jobprep 하네스의 일부를 옮겨 오면서 **일부러 충돌을 넣은** 견본이다(7장 5절). 실제 저장소에 복사하지 않는다. 읽기만 한다.

| 파일 | 내용 |
|---|---|
| `CLAUDE.md` | 팀 규칙 7개 |
| `.claude/rules/api.md` | API 코드의 경로별 규칙 |
| `.claude/settings.json` | 권한 규칙과 훅 |
| `.claude/skills/incident-report/SKILL.md` | 장애 보고서 스킬(발췌) |

## 할 일

1. 네 파일을 읽고 서로 부딪치는 곳을 모두 찾는다. 충돌은 적어도 여섯 군데에 있다.
2. 찾은 충돌마다 종류를 붙인다: 규칙과 규칙, 규칙과 권한, 규칙과 훅(지시와 강제의 중복 포함), 규칙과 스킬, 규칙과 저장소 규약.
3. 충돌마다 어느 쪽을 남기고 어느 쪽을 지울지, 그 까닭을 한 줄로 적는다. 판단 기준은 7장 5절의 「충돌을 푸는 순서」이다.

결과는 `docs/운영/하네스설계서.md`의 「8. 충돌과 해결」 절에 옮겨 적는다.
