## 9. 측정 계획

| 항목 | 내용 |
|---|---|
| 가설 | (예: 하네스가 있으면 규칙 위반이 줄고 인수 통과율이 오른다. 토큰과 시간은 늘어난다) |
| 작업 | T1, T2, T3 (작업 카드). 직접 실행하는 것은 T2 한 건의 두 조건(7장의 실행 상한), T1·T3는 교수 시연 기록 |
| 조건 | 하네스 없음(off), 있음(on). 같은 기준 태그, 같은 모델, 같은 실행 옵션 |
| 반복 | 조건마다 (n)회 |
| 지표 | 인수 통과율, 전체 테스트, 규칙 위반 수, 사람 개입 횟수, 소요 시간, 토큰, 비용 |
| 판정 기준 | (무엇이 어떻게 나오면 하네스가 효과가 있다고 볼 것인가를 실행 전에 적는다) |
| 통제하지 못한 것 | (사용자 범위 설정, 모델의 비결정성 등) |
