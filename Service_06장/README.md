# 6장 키트: 코드의 리버스 엔지니어링

「LLM 서비스 개발」 6장(학사 7주차, 서비스 2: 명령줄 도구)의 실습 재료이다. 강의안은 `Service_06장_학생용.md`이다. 분석 대상은 파이썬 표준 라이브러리의 `python -m json.tool`이며, 대상 프로그램은 키트에 넣지 않는다. 각자의 PC에 설치된 파이썬의 파일을 읽는다.

## 받는 법

부록 A-12-3의 형식을 따른다.

```bash
git -C ~/kits-repo pull
mkdir -p ~/kits
cp -rn ~/kits-repo/Service_06장 ~/kits/
ls ~/kits/Service_06장
```

작업 폴더로 복사하는 명령은 강의안 0절에 있다.

- 모든 코드는 파이썬 표준 라이브러리와 Git Bash의 기본 명령(`cmp`, `diff`, `od`)만 쓴다. 설치할 패키지가 없다(`requirements.txt` 없음).
- `compare.sh`는 `bash compare.sh`로 실행하므로 실행 권한이 필요 없다.
- `compare.sh`는 경우 파일의 줄 끝에 붙은 `\r`을 지우고 읽는다. Windows의 편집기가 CRLF로 저장한 `cases.txt`에서 파일 이름 끝에 `\r`이 붙으면, 원본과 재구현이 모두 「파일 없음」으로 실패해 「같다」가 나오기 때문이다(2026-11-18 확인).
- `< a.json --sort-keys`처럼 `<`와 파일 이름으로 시작하는 줄은 그 파일을 표준 입력으로 준다. 그 밖의 줄에는 빈 표준 입력을 준다.
- 이 장에서 실제 모델을 쓰는 곳은 Claude Code의 대화형 세션뿐이다(3-6 추출, 4-1 재구현).

## 순서

1. 0절: 작업 폴더 `~/llm-service-lab/ch06/cli/`를 만들고 `시험자료/`와 `양식/`을 복사한다.
2. 2절: 관찰하고 `관찰기록.md`를 쓴다.
3. 3절: 코드를 읽어 인자 표를 쓰고, Claude Code로 `명세.md`를 뽑고, 근거를 뺀 `재구현/명세.md`를 만든다.
4. 4절: 새 세션에서 `재구현/jsonfmt.py`를 만든다.
5. 5절: `대조/`의 두 파일을 `재구현/`에 복사해 대조하고 `비교.md`를 쓴다.
6. 6~7절: `추적표.md`를 쓰고 핵심 실습을 마친 뒤 커밋한다.

## 실행 확인의 기록

2026-11-18, Windows 11(빌드 26300), Git Bash(GNU bash 5.3.15), Python 3.13.7(python.org 설치본), `PYTHONUTF8=1`에서 `교수/리허설.sh`로 강의안의 명령을 모두 실행하였다. 견본 재구현 v1의 대조는 「같다 2, 다르다 4」, v2는 「같다 6, 다르다 0」, 확장한 경우 20줄은 「같다 14, 다르다 6」이었다. Python 3.14.6(Anaconda)에서는 `json/tool.py`가 122줄이고 사용법의 첫 줄이 `python.exe -m json.tool`로 바뀌며, `--json-lines`의 파일 입력이 동작하였다.
