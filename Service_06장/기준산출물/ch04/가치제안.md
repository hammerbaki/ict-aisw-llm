# 가치 제안: 취업 준비 지원 서비스

- 틀: 가치 제안 캔버스(Strategyzer)의 고객 프로필과 가치 맵
- 고객 세그먼트: 전문대학 2학년 취업 준비생 (졸업 학년)
- 상태: 가설. 고객 프로필의 항목은 2차 자료와 수강생 자신의 경험에서 쓴 것이며, 5장의 동료 인터뷰로 확인한다. 「확인 근거」 열이 비어 있는 항목은 아직 확인되지 않은 것이다.

## 1. 고객 프로필

### 1-1. 고객 업무

| 번호 | 업무 | 종류 | 확인 근거 |
|---|---|---|---|
| J1 | 지원할 만한 공고를 찾고 고른다 | 기능 | 주된 취업경로 1위가 신문·잡지·인터넷 등 응모다 (시장조사 S3) |
| J2 | 공고마다 다른 마감일과 전형 일정을 챙긴다 | 기능 | |
| J3 | 공고에 맞추어 자기소개서를 고쳐 쓴다 | 기능 | |
| J4 | 졸업 전에 취업이 정해졌다는 것을 가족과 동기에게 보여 준다 | 사회 | |
| J5 | 졸업이 다가오는데 준비가 늦었다는 불안을 줄인다 | 감정 | |

### 1-2. 불편

| 번호 | 불편 | 관련 업무 | 확인 근거 |
|---|---|---|---|
| P1 | 공고가 여러 사이트에 흩어져 같은 공고를 여러 번 본다 | J1 | 경쟁 서비스 5개가 각각 공고 목록을 가진다 (비교표) |
| P2 | 마감일을 놓친다 | J2 | |
| P3 | 공고의 자격 요건을 읽는 데 시간이 걸린다 | J1 | |
| P4 | 자기소개서를 누구에게 봐 달라고 하기 어렵다 | J3 | |
| P5 | 첫 일자리까지 오래 걸릴 수 있다는 불안 | J5 | 대졸이상 첫 취업 평균 소요기간 8.5개월 (시장조사 S3) |

### 1-3. 이득

| 번호 | 이득 | 관련 업무 | 확인 근거 |
|---|---|---|---|
| G1 | 내 전공과 학년에 맞는 공고만 본다 | J1 | |
| G2 | 이번 주에 할 일이 한 화면에 보인다 | J2 | |
| G3 | 제출 전에 자기소개서의 고칠 곳을 안다 | J3 | |
| G4 | 준비가 어디까지 왔는지 숫자로 본다 | J5 | |

## 2. 가치 맵

### 2-1. 제품·서비스

- 공고 모아보기와 지원 일정 관리 웹 (9장)
- 공고 요약 기능 (10장)
- 취업 자료 질의응답 (11장)
- 자기소개서 피드백 (10장의 LLM 기능 확장)

### 2-2. 불편 해소

| 불편 | 해소 방법 |
|---|---|
| P1 | 관심 공고를 한 목록에 모은다 |
| P2 | 지원하기로 한 공고의 마감일을 일정에 넣고 남은 날을 보여 준다 |
| P3 | 공고 요약이 자격 요건과 마감일을 먼저 보여 준다 |
| P4 | 제출 전에 공고와 자기소개서를 대조한 피드백을 준다 |

### 2-3. 이득 창출

| 이득 | 창출 방법 |
|---|---|
| G1 | 전공과 졸업 예정 시기로 공고를 거른다 |
| G2 | 이번 주 할 일 목록 |
| G3 | 자기소개서 피드백 |
| G4 | 지원 단계별 진행 현황 |

## 3. 적합 점검

| 고객 프로필 항목 | 대응하는 가치 맵 항목 | 상태 |
|---|---|---|
| J1·P1·P3·G1 | 공고 모아보기, 공고 요약, 거르기 | 대응함 |
| J2·P2·G2 | 지원 일정 관리 | 대응함 |
| J3·P4·G3 | 자기소개서 피드백 | 대응함 |
| J4 | (없음) | 대응하지 않음. 범위 밖으로 둔다 |
| J5·P5·G4 | 진행 현황 | 부분 대응 |

## 4. 가치 제안 문장

> 전문대학 2학년 취업 준비생이 여러 사이트에 흩어진 공고와 마감일을 챙기고 자기소개서를 고쳐 쓸 때, 공고 요약과 지원 일정과 자기소개서 피드백을 한 화면에 모아 준비 시간을 줄인다. 공고를 모아 보여 주는 서비스와 달리, 학생이 지원할 공고의 일정과 서류를 끝까지 관리하게 한다.

## 5. 이 가치 제안이 기대는 가정 (5장에서 확인할 것)

- P2(마감일을 놓친다)와 P4(자기소개서를 봐 줄 사람이 없다)가 실제로 큰 불편인가.
- J4(사회적 업무)를 범위 밖으로 둔 판단이 맞는가.
- 동료 인터뷰에서 위 목록에 없는 업무와 불편이 나오는가.
