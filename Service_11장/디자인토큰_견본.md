# 디자인 토큰: 메모장 웹 재구현

- 판: v0.1 (11장 견본)
- 원본: 이 파일이 토큰의 유일한 원본이다. `prototype/tokens.css`는 `tools/tokens_to_css.py`가 이 파일에서 만든다.
- 형식: 표 한 줄이 토큰 하나다. 첫 칸은 이름, 둘째 칸은 값이며 둘 다 백틱으로 감싼다. 값에서 다른 토큰을 `{이름}`으로 가리킬 수 있다(W3C 디자인 토큰 형식의 별칭 문법).
- 계층: 기본 토큰(값 자체)과 의미 토큰(용도. 기본 토큰을 가리킨다)의 두 층으로 둔다. 화면의 CSS는 의미 토큰만 쓴다.
- 출처: `navy-90`, `gray-60`은 FromScratch v1.4.3의 `app/assets/style/app.scss`에 있는 바탕색과 글자색이다. `navy-80`, `gray-50`은 같은 앱의 저장 안내 문구(`.nosave`)의 반투명 색을 바탕 위에 합성한 값이다(2026-11-18 계산). **이 견본에는 기준에 못 미치는 대비 쌍이 하나 들어 있다.** 원본의 값을 그대로 옮겼기 때문이다.

## 1. 색

### 1-1. 기본 색

| 토큰 | 값 | 설명 |
|---|---|---|
| `navy-90` | `#002b36` | 가장 어두운 남색. 원본의 바탕 |
| `navy-80` | `#1a404a` | 어두운 남색. 원본 안내 상자의 합성색 |
| `gray-20` | `#d3dcdc` | 밝은 회색 |
| `gray-50` | `#758d92` | 중간 회색. 원본 안내 문구의 합성색 |
| `gray-60` | `#829696` | 중간 회색. 원본의 본문 글자 |
| `amber-40` | `#e0b04a` | 밝은 주황 |
| `red-30` | `#ff8a80` | 밝은 빨강 |

### 1-2. 의미 색

| 토큰 | 값 | 용도 |
|---|---|---|
| `color-bg` | `{navy-90}` | 화면 바탕, 입력 칸의 바탕 |
| `color-text` | `{gray-60}` | 메모 본문 글자 |
| `color-text-strong` | `{gray-20}` | 제목, 단추의 글자 |
| `color-status-bg` | `{navy-80}` | 저장 상태 영역의 면 |
| `color-status-text` | `{gray-50}` | 저장 상태 문구 |
| `color-danger` | `{red-30}` | 저장 실패 문구 |
| `color-focus` | `{amber-40}` | 초점 표시 테두리 |

## 2. 글꼴과 크기

| 토큰 | 값 | 용도 |
|---|---|---|
| `font-family-base` | `"D2Coding", "Noto Sans KR", monospace` | 모든 글자 |
| `font-size-body` | `1rem` | 본문 16px |
| `font-size-status` | `0.875rem` | 저장 상태 문구 14px |
| `line-height-body` | `1.5` | 본문 줄 높이 |

## 3. 간격과 크기

| 토큰 | 값 | 용도 |
|---|---|---|
| `space-2` | `0.5rem` | 묶음 안의 간격 8px |
| `space-3` | `1rem` | 묶음 사이의 간격 16px |
| `size-target-min` | `2.75rem` | 단추의 최소 높이 44px |
| `focus-ring-width` | `3px` | 초점 표시 두께 |

## 4. 대비 쌍

`python tools/contrast.py 디자인토큰.md`가 이 표의 쌍을 판정한다. 기준은 글자 4.5(WCAG 2.2의 1.4.3), 초점 표시 같은 UI 요소 3(1.4.11)이다.

| 전경 | 배경 | 기준 | 용도 |
|---|---|---|---|
| `color-text` | `color-bg` | 4.5 | 메모 본문 |
| `color-text-strong` | `color-bg` | 4.5 | 제목과 단추 |
| `color-status-text` | `color-status-bg` | 4.5 | 저장 상태 문구 |
| `color-danger` | `color-status-bg` | 4.5 | 저장 실패 문구 |
| `color-focus` | `color-bg` | 3 | 초점 표시 |
