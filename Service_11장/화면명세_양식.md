- 판: v0.1
- 입력: `ch11/기능명세.md`(요구 ID), `ch11/관찰기록.md`, 디자인토큰(쓰는 경우)
- 이 파일은 기능과 문구의 기준이다. 배치는 각 화면의 와이어프레임이 기준이다. 둘이 어긋나면 구현자는 임의로 정하지 않고 묻는다.

## SCR-0N. 「화면 이름」

### 1) 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | SCR-0N |
| 목적 | 「이 화면에서 사용자가 끝내는 일 한 문장」 |
| 관련 요구 | 「REQ-01, REQ-02」 (쉼표로 이어 줄여 쓰지 않는다) |
| 들어오는 길 | 「앱을 열면, 또는 어느 화면의 무엇을 눌러서」 |
| 나가는 길 | 「무엇을 누르면 어디로」 |

### 2) 와이어프레임

좁은 화면 배치를 먼저 그리고, 넓은 화면에서 달라지는 점을 아래에 적는다.

```text
「ASCII 와이어프레임」
```

넓은 화면(「중단점」 이상): 「무엇이 어떻게 바뀌는가」
