# 키트 저장소

「LLM 서비스 개발」(Service_NN장)과 「AI에이전트 기획 및 개발」(Agent_NN장)의 실습 키트이다.
장 폴더는 수업이 진행되는 대로 하나씩 올라온다.

## 받는 법

처음 한 번: Google 클래스룸에 올린 주소로 `~/kits-repo`에 클론한다(부록 A-12-2 / A-7-2).
장마다: 그 장 강의안 0절의 첫 명령을 친다.

    git -C ~/kits-repo pull
    cp -rn ~/kits-repo/<장 폴더> ~/kits/

## 약속

- 이 폴더(`~/kits-repo`) 안의 파일을 고치지 않는다. 고치면 다음 `pull`이 거절될 수 있다.
  작업은 `~/kits/`에 복사한 것으로 한다.
- 제출은 Google 클래스룸의 과제로 한다. 이 저장소에는 아무것도 올리지 않는다.
