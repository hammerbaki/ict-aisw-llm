# 채용 공고 발췌 (실습용 가상 문서)

이 문서는 「LLM 서비스 개발」 10장의 검색 증강 생성 실습을 위해 만든 가상 채용 공고 모음이다. 회사 이름과 내용은 모두 지어낸 것이며, 실제 기업이나 공고와 관계없다. 학과 취업지원실이 2027년 4월에 학생에게 소개한 공고를 가정하였다.

## 공고 A: 누리소프트(가상) 신입 백엔드 개발자

누리소프트는 중소기업용 근태 관리 서비스를 만드는 회사이다. 주요 업무는 파이썬과 FastAPI로 만든 API 서버의 기능 개발과 유지 보수이다. 자격 요건은 전문학사 이상, 파이썬으로 웹 API를 만들어 본 경험이며, Git과 풀 리퀘스트 기반 협업 경험을 우대한다. 전형은 서류 전형, 온라인 코딩 테스트, 기술 면접, 임원 면접의 순서이다. 지원 마감은 2027년 4월 30일 오후 6시이며, 회사 채용 누리집에서만 지원을 받는다.

## 공고 B: 다온헬스케어(가상) AI 서비스 개발 인턴

다온헬스케어는 병원 예약과 건강 상담 챗봇을 운영하는 회사이다. 이 공고는 6개월 채용 연계형 인턴이며, 인턴 기간이 끝난 뒤 평가를 거쳐 정규직 전환을 검토한다. 주요 업무는 상담 챗봇의 대화 기록 분석과 LLM API를 이용한 기능 시험이다. 자격 요건은 졸업 예정자 또는 졸업 후 2년 이내인 사람이며, LLM API나 검색 증강 생성(RAG)을 써 본 경험을 우대한다. 근무지는 서울이며 주 2일 재택근무가 가능하다. 지원 마감은 2027년 5월 14일이다.

## 공고 C: 바른물류(가상) QA 엔지니어 신입

바른물류는 택배 배송 추적 앱을 운영하는 회사이다. 주요 업무는 앱과 웹의 기능 시험, 시험 자동화 스크립트 작성, 결함 보고서 작성이다. 자격 요건은 전문학사 이상이며, pytest나 Selenium 같은 시험 도구 사용 경험을 우대한다. 정보처리산업기사 이상의 자격증 보유자를 우대한다. 전형은 서류 전형, 직무 면접, 최종 면접이며, 지원 마감은 채용 시까지이다.
