# 시연기록: 교수 시연의 실행 기록

이 폴더에는 교수가 수업 전에 교수 계정에서 만든 실행 기록 `10장_시연기록.md`가 들어간다. 교수가 키트 저장소의 `Service_10장/시연기록/`에 올린다. 학생 대부분이 직접 실행하지 않는 두 단계의 결과다.

- **Ollama 임베딩 경로.** 이 장의 기본은 키트의 대체 임베딩이다(`EMBED_BACKEND`의 기본값 `fallback`). 자기 PC에 Ollama를 설치한 학생은 같은 측정을 직접 해 볼 수 있지만 선택이다(부록 A-17). 의미 임베딩의 결과는 이 기록으로 본다.
- **실제 모델의 답.** 프로덕트의 LLM 호출은 모의 모드(`LLM_FAKE=1`)가 기본이고, Console 키는 각자 발급하는 선택이다(부록 A-14). 키가 있는 학생도 이 장에서는 `python -m rag ask` 1회까지만 실제로 부른다. 여러 질문의 실제 답은 이 기록으로 본다.

기록의 절과 강의안의 절은 다음처럼 대응한다.

| 기록의 절 | 내용 | 강의안 |
|---|---|---|
| 1 | 세 쌍의 유사도 | 2-3 |
| 2 | 색인, 세 검색 방법의 재현율 | 3-3, 8-5 |
| 3 | 기본 설정의 결과표 | 8-5 |
| 4 | 고정 길이 200자와 겹침 50의 재측정 | 8-7, 8-8 |
| 5 | 기준값(`calibrate`)과 범위 밖 질문 | 8-6 |
| 6 | 증강 프롬프트와 답 | 8-6 |
| 7 | 숨은 지시가 든 공고(교수 시연) | 1-2 |

기록의 머리말에 임베딩 경로, 생성 방식(실제 호출 또는 모의 모드), 기준값이 적혀 있다. 숫자가 자기 화면과 다른 것이 정상이다. 숫자를 자기 `docs/검색평가.md`의 결과표에 옮겨 적지 않고, 견준 결과만 7절에 문장으로 적는다.

수업 전에 기록이 올라오지 않았으면 이 안내 파일만 있다. 기록이 올라온 뒤 다시 받는다.

```bash
git -C ~/kits-repo pull
cp -rn ~/kits-repo/Service_10장/시연기록 ~/kits/Service_10장/
```
