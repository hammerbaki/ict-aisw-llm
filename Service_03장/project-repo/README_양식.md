## 작업 규칙

1. `main`에 직접 커밋하지 않는다. 이슈 → 브랜치 → 풀 리퀘스트 → 리뷰 → 병합으로 작업한다.
2. 브랜치 이름: `<이슈 번호>-<동사>-<대상>` (예: `12-add-persona`)
3. 풀 리퀘스트 설명에 `Closes #<이슈 번호>`를 적는다. 승인 1개 이상을 받은 뒤 병합한다.
4. 작업을 시작하기 전과 푸시하기 전에 `git pull`로 원격을 받는다. 강제 푸시를 하지 않는다.
5. 비밀번호, API 키, `.env` 파일을 커밋하지 않는다.
